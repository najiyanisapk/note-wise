📚 Notewise – Smart Study Companion

Notewise is a student-friendly study website designed to make learning, note management, and exam preparation easier. It aims to help students organize their study materials and prepare for exams in one place.

✨ Features

- 📝 Study Notes: Organize and access study notes.
- 📖 Topic-wise Learning: Find questions and answers by topic.
- 📚 Book References: Keep useful textbook references organized.
- ❓ Doubt Support: Get help with study questions.
- 📝 Model Exams: Prepare for exams with practice questions.
- 📂 Study Material Management: Keep learning resources organized.

🎯 Purpose

The goal of Notewise is to provide a simple and convenient study space where students can manage learning resources and improve their exam preparation.

- CSS
- JavaScript
